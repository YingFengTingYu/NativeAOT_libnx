# 2026-09-08：iOS 7 ARM64 首轮适配

## 环境与基线

- macOS 26.5.1，Apple Silicon。
- Xcode 26.3 / Apple Clang 17.0.0。
- 从 Xcode 7.3.1 提取 iOS 9.3 SDK。
- `dotnet/runtime` 基线 `v10.0.7`，NuGet 运行时包 `10.0.7`。
- 标准 iOS NativeAOT、ILCompiler 和基础库构建通过：0 个警告、0 个错误。

## 实际验证

| 检查 | 结果 | 范围 |
|---|---|---|
| iOS 7 ARM64 NativeAOT 原生运行时 | 构建通过 | Workstation GC、Server GC 和辅助库；不代表实机运行 |
| 旧 SDK 下的 System.Native | 构建通过 | 基础系统接口 |
| Mach 时钟后备实现 | 本机通过 | 8 线程，与系统单调时钟交叉比较 |
| TLS 汇编入口 | 本机通过 | 两个入口，x1–x17、v0–v31 的完整 128 位内容 |
| pthread TLS 的实际 NativeAOT 程序 | 本机通过 | 7 组功能测试，包括 GC、异常、32 次托管线程生命周期、32 次混合参数回调、Task 和文件 |
| ILCompiler 版本参数 | 通过 | 默认 12.2、自定义 7.0、无效版本拒绝 |
| 最终 iOS 探针 | 链接与静态检查通过 | ARM64，最低 7.0，SDK 9.3；无原生 TLS section 和已列出的新系统入口 |
| 测试产物签名 | 本机检查通过 | ad-hoc，SHA-1/SHA-256 双摘要；不代表设备已接受 |
| iOS 7 真机 | 未执行 | 尚无对应系统的实机验证结果 |
| iOS 10 真机 | 未执行 | 已识别 iPad mini 4 / iOS 10.0.2 并验证 USB 配对，SSH 尚未响应 |

## 限制

本轮验证的是原生运行时与所列探针覆盖的功能。探针不使用现代 Apple 加密和 Network.framework，不能由此推出完整加密、TLS/HTTP、所有 .NET 基础库或游戏已经兼容。ARM32 仍需单独适配。

本机运行使用 macOS 构建的同一套 pthread TLS 运行时；它能验证存储隔离、退出清理与调用约定，但不能验证旧 iOS 内核及框架行为。针对 4 KiB 页面的代码路径仍需相应设备验证。
