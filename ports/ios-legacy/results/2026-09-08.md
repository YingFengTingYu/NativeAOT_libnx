# 2026-09-08：iOS 7 ARM64 首轮适配

## 环境与基线

- macOS 26.5.1，Apple Silicon。
- Xcode 26.3 / Apple Clang 17.0.0。
- 从 Xcode 7.3.1 提取 iOS 9.3 SDK。
- `dotnet/runtime` 基线 `v10.0.7`，NuGet 运行时包 `10.0.7`。
- 标准 iOS NativeAOT、ILCompiler 和基础库构建通过：0 个警告、0 个错误。

## 实际验证

| 检查 | 结果 | 范围 |
|---|---|---|
| iOS 7 ARM64 NativeAOT 原生运行时 | 构建通过 | Workstation GC、Server GC 和辅助库；不代表实机运行 |
| 旧 SDK 下的 System.Native | 构建通过 | 基础系统接口 |
| Mach 时钟后备实现 | 本机通过 | 8 线程，与系统单调时钟交叉比较 |
| TLS 汇编入口 | 本机通过 | 两个入口，x1–x17、v0–v31 的完整 128 位内容 |
| pthread TLS 的实际 NativeAOT 程序 | 本机通过 | 7 组功能测试，包括 GC、异常、32 次托管线程生命周期、32 次混合参数回调、Task 和文件 |
| ILCompiler 版本参数 | 通过 | 默认 12.2、自定义 7.0、无效版本拒绝 |
| 最终 iOS 探针 | 链接与静态检查通过 | ARM64，最低 7.0，SDK 9.3；无原生 TLS section 和已列出的新系统入口 |
| 测试产物签名 | 本机与 iOS 10 真机通过 | 原始 `codesign` SHA-1/SHA-256 双摘要产物和 `ldid` SHA-1 带空 entitlements 字典产物均完成 7 组测试 |
| iOS 7 真机 | 未执行 | 尚无对应系统的实机验证结果 |
| iOS 10 真机 | 7 组测试全部通过 | iPad mini 4 / iOS 10.0.2（14A456），Meridian，16 KiB 系统页；`PASS ALL (7 suites)`，退出码 0 |

## iOS 10 真机结果

测试运行时代码为提交 `fbbefea22330cd0b483c06c48e0719264e993c72`，最终产物仍记录最低 iOS 7.0、SDK 9.3，并使用 pthread TLS。2026-09-08 19:49 与 19:50（UTC+8）在 iPad 上分别运行两个签名版本，均得到：

```text
PASS clock
PASS gc
PASS exceptions
PASS threads
PASS callbacks
PASS tasks
PASS files
PASS ALL (7 suites)
退出码：0
```

覆盖强制压缩 GC 和终结器、显式与空引用异常、32 次托管线程生命周期及 ThreadStatic 隔离、32 次含整数与浮点参数的原生回调（其中 16 次由外部 pthread 发起）、Task/定时器，以及中文文件内容往返。普通 C 探针在同一设备上测得系统页大小为 16384 字节。

### 执行目录限制

USB House Arrest 传入 Meridian 数据容器后，回读文件与本地产物一致。直接从应用数据目录或 `/var/tmp` 启动时，即使 root 与 755 权限也返回 `Operation not permitted`（126）；内核日志明确记录 `SandboxViolation ... System Policy: deny process-exec`。普通 C 程序和设备 `/bin/ls` 的副本也受到相同限制。

将程序复制到 `/usr/local/libexec/NativeAOTProbe-fbbefea22` 后，普通 C 程序、`ls` 副本和 NativeAOT 均能运行。最初的 `codesign` 双摘要产物也通过全部测试，因此这次启动失败不能归因于 NativeAOT 或双摘要签名。此结论来自该设备上的目录对照，不推广为所有越狱环境的通用规则。复现命令见 [README](../README.md#真机验证)。

## 限制

本轮验证的是原生运行时与所列探针覆盖的功能。探针不使用现代 Apple 加密和 Network.framework，不能由此推出完整加密、TLS/HTTP、所有 .NET 基础库或游戏已经兼容。ARM32 仍需单独适配。

iOS 10 真机结果补充了 ARM64 上运行时启动、线程退出清理、GC、异常和回调的验证，但不能证明 iOS 7 系统接口或内核行为兼容。该 iPad 使用 16 KiB 页，针对 4 KiB 页面的代码路径仍需相应设备验证。
